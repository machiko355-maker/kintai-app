勤怠表アプリ 取扱説明書

複数のポジションを、決まった人数でローテーションする勤怠表を作るアプリです（Android / iPhone / ブラウザ対応）

1. アプリを入れる（QRコード）

お使いの端末に合わせて、スマホのカメラでQRコードを読み取ってください。

Android https://github.com/machiko355-maker/kintai-app/releases/latest/download/kintai.apk
iPhone（iOS） https://machiko355-maker.github.io/kintai-app/
ブラウザ版 https://machiko355-maker.github.io/kintai-app/

iPhone とブラウザ版は同じURLです。iPhone では Safari で開いてください。

Android（APKをインストール）

  1. 上のAndroidのQRコードを読み取ると、ファイル（kintai.apk）のダウンロードが始まります。
  2. ダウンロードが終わったら、通知またはファイルアプリからkintai.apkをタップします。
  3. 「提供元不明のアプリ」の許可を求められたら、許可します（ブラウザやファイルアプリに対する許可です）。
  4. 「インストール」を押します。「Playプロテクト」の警告が出た場合は、「詳細」→「インストールする」を選びます。

「IT管理者によりブロックされました」と出る場合は、その端末でアプリの追加が禁止されています。ブラウザ版（下記）を使うか、管理者に相談してください。

iPhone（ホーム画面に追加）

iPhone 用のアプリ（App Store版）は用意していません。代わりにSafariから「ホーム画面に追加」すると、アプリのように使えます。

  1. iPhone の Safari で、iPhone のQRコードを読み取ってページを開きます。
  2. 画面下の共有ボタン（四角から上向き矢印のマーク）を押します。
  3. 「ホーム画面に追加」を選び、右上の「追加」を押します。
  4. ホーム画面にできた「勤怠表」のアイコンから起動します。

Chromeなど Safari 以外のブラウザでは「ホーム画面に追加」から通知が使えないことがあります。通知を使う場合は、必ずSafariから追加してください（iOS 16.4 以降）。

ブラウザ版（インストール不要）

スマホやパソコンのブラウザでURLを開くだけで使えます。Android の Chrome では、メニュー（⋮）の「ホーム画面に追加」でアイコンを作れます。ブラウザ版は、開くたびに自動で最新になります。

2. 画面の構成と、勤怠表の準備

画面の下に3つのタブがあります。

タブ内容
勤怠作成対象月・メンバー・ポジション・休日・休暇を設定し、勤怠表を作ります。
勤怠表作った勤怠表を見ます。月の切り替え、作り直し、コピー、CSVもここです。
設定共有（データベース・共有コード・ログイン）の設定です。

「勤怠作成」タブでの準備

項目やること
対象月勤怠表を作る月を選びます。横の「更新」ボタンで、共有された最新データを取り込めます。
メンバー名前を入力して「追加」。× で削除します。
ポジションと人数ポジション名と、1日に必要な人数を入力します。「＋ ポジション追加」で増やせます。
任意の休日土日祝日は自動で休みになります。それ以外の休みの日（会社の休業日など）を、日付を選んで追加します。
休暇休暇を取るメンバーにチェックを入れ、開始日と終了日を選んで「まとめて追加」を押します。複数のメンバーと複数日を、一度に登録できます（「全員選択」も使えます）。1日だけの場合は、終了日を空にします。土日祝日などの休みの日は、自動で対象外です。登録した内容は、下の一覧に表示され、× で削除できます。
例：AさんとBさんが、10/20〜10/24 の5日間休む場合は、AさんとBさんにチェックを入れ、開始日に10/20、終了日に10/24を選んで「まとめて追加」を押します。
ポジションの必要人数の合計がメンバー数を超えると、空きが出ます。画面に警告が出ます。

3. 複数人で共有する

同じ「共有コード」を入力した人どうしで、メンバー・ポジション・休日・休暇・勤怠表が共有されます。誰かが変更すると、他の人の画面にも自動で反映されます（約10秒ごと）。

  1. 「設定」タブを開き、「共有」欄を表示します。データベースURLとWeb APIキーは最初から入っています。
  2. 共有コードを入力します。管理者から教えられた文字列を、全員が同じように入力してください。
  3. 「共有開始」を押します。通知の許可を求められたら、許可します。
  4. メールアドレスとパスワード（6文字以上）を入力し、初めての人は「新規登録」、2回目以降は「ログイン」を押します。

共有コードを知っていてログインした人は、全員が編集できます。共有コードは、関係者以外に教えないでください。

4. 勤怠表を作る・見る

  1. 「勤怠作成」タブで、メンバー・ポジション・休日・休暇を確認し、「勤怠表を作成」を押します。
  2. 「勤怠表」タブに、日付ごとの担当者が表示されます。

ローテーションのルール

  • 土日祝日と、登録した休日は休みです。
  • 同じ人が2日続けてポジションに入らないよう、できるだけ避けます。人数の都合で避けられない場合は、最小限に抑え、その回数を画面に表示します。
  • 出勤回数とポジションの偏りが、できるだけ少なくなるように割り振ります。
  • 休暇の人は、その日のローテーションから外れます。

勤怠表の画面

操作説明
◀ 前月 / 翌月 ▶画面の一番上のボタンで、月を切り替えます。月ごとに別々の表を保存できます。表がない月は「この月を作成」で作れます。
更新共有された最新のデータを取り込みます。アプリの新バージョンがあるかも確認します。
作り直す確認画面で「OK」を押すと、その月の表を作り直します。現在の内容は破棄されます。
コピー表の内容をコピーします。メモやメッセージに貼り付けられます。
CSVExcelなどで開けるファイルとして、共有・保存します。

表をスクロールしても、ポジション名の行と日付の列は固定されたままです。表の下の「集計」で、各人の出勤回数・ポジション別の回数・休暇の日数を確認できます。

5. 通知

他の人が勤怠表を作り直すと、「勤怠表が作り直されました」と通知が出ます。

  • 初めて共有を開始したときや、ログインしたときに、通知の許可を求められます。許可してください。
  • 通知が届くのは、アプリを開いているときや、アプリの画面に戻ったときです。アプリを完全に閉じている間は届きません。
  • 通知が来たときは、「更新」ボタンで最新の表を確認してください。
  • 通知が出ないときは、端末の設定でこのアプリの通知がオフになっていないか確認してください。

6. アプリの更新

  • Android（APK版）：新しいバージョンがあると、画面の上に黄色い案内が出ます。「更新する」を押してダウンロードし、ファイルをタップして上書きインストールします。入力したデータは消えません。
  • iPhone・ブラウザ版：開くだけで自動的に最新になります。表示が古いときは、ページを再読み込みしてください。

7. 困ったとき

状況対処
「IT管理者によりブロックされました」と出る端末の管理者が、アプリの追加を禁止しています。ブラウザ版を使うか、管理者に許可を相談してください。
共有されない・「通信できません」と出るネットワークに接続しているか確認してください。ログインしているか、共有コードが全員同じかも確認してください。
「メールまたはパスワードが違います」と出る入力内容を確認してください。初めての人は「新規登録」を押します。
他の人の変更が反映されない「更新」ボタンを押してください。
同時に編集して内容が食い違った後から保存した内容が残ります。大きな変更は、声をかけ合って行ってください。
連日勤務が出てしまうメンバー数に対してポジションの必要人数が多いと、避けられません。人数を見直すか、「作り直す」を試してください。

8. 管理者向けメモ

  • データはFirebase（Realtime Database）に保存されます。ルールは、ログイン済みのユーザーだけが読み書きできる設定にしてください。
  • 新規登録できる人を制限したい場合は、Firebaseの「Authentication」で、ユーザーの管理や新規登録の制限を設定します。
  • 新バージョンは、GitHubの Release に公開されます（リリース一覧）。
